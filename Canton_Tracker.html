Connect this dashboard

  1. Open Canton_Tracker_SheetTemplate.csv in Google Sheets (File → Import → Upload).
  2. File → Share → Publish to web, set the format to Comma-separated values (.csv), click Publish. Paste that link below.
  3. Follow SETUP_INSTRUCTIONS.md to deploy the Apps Script and create an OAuth client ID, then paste both below. Leave them blank for read-only mode.

Sign in to update the tracker

Access is granted by the project administrator. Sign in with the Google account that was added to the access list.

Updates awaiting approval

Submissions from contributors. Approving writes the change to the tracker and the sheet; rejecting discards it. Every decision is logged with your name.
